# 🎌 Anime Tracker v1.0.0

**Tu lista de anime personal** — app de escritorio con estadísticas, notificaciones, sincronización con Google Sheets y acceso móvil.

## ✨ Características

- **8 fuentes** de búsqueda: AniList, Jikan v4, Kitsu, Crunchyroll, AnimeFLV, AnimePlanet, AnimeAV1, MAL
- Buscador con **vista previa** antes de añadir
- Vista **grid** o **tabla compacta**
- Listas personalizadas, favoritos, temporada, puntuación, notas
- **Drag & drop** entre listas
- **Atajos de teclado**: `/` buscar, `Esc` cerrar, `N` nuevo
- Estadísticas con **donut chart** y genre pills
- Noticias y novedades anime en tiempo real
- Recomendaciones automáticas por géneros
- **Web Notifications** para nuevos episodios
- Calendario semanal de episodios
- Google Sheets sync (opcional)
- Acceso **móvil** por WiFi local (PWA instalable)
- 4 idiomas: ES / EN / FR / DE
- Modo claro y oscuro

## 🚀 Uso rápido

```bash
git clone https://github.com/TU_USUARIO/anime-tracker.git
cd anime-tracker
pip install -r requirements.txt
python main.py
```
Abre `http://localhost:8765`

## 📱 Móvil

PC: 📱 Móvil → PIN → Activar → Reiniciar app
Móvil: misma WiFi → `http://IP:8765/app` → Añadir a pantalla inicio

## 🛠 Compilar instalador Windows

```bash
compilar.bat
```
